# Shopping Cart

A responsive shopping cart application built with HTML, CSS, and JavaScript.

## Live Demo

[View Shopping Cart](https://ammughal13.github.io/Shopping-Cart/)

## Features

- Dynamic product listing
- Search products by name
- Filter products by category
- Add products to the cart
- Increase and decrease item quantities
- Automatically calculate the cart total
- Remove individual items
- Clear the entire cart
- Save cart data using LocalStorage
- Responsive layout for mobile and desktop screens

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Purpose

This project was built to practise front-end web development, DOM manipulation, event handling, arrays, objects, and browser LocalStorage.
